# ASIT Creative Direction — v0.3.8 acceptance (Level 1)

This is a **manual host QA checklist**, not evidence of validated host UI, media playback or user satisfaction. Run it after updating the installed private plugin in a **fresh regular ChatGPT chat**, on desktop and mobile where possible.

| Prompt | Pass criteria |
| --- | --- |
| `Продолжим` | One authentic can-do, coherent scenario/outcome, thoughtful premium editorial presentation, 5 varied tasks default; not five unrelated text radios. |
| `Use a picture to teach in/on/under` | Actual verified source image whose contents distinguish answers, or a real symbolic diagram with user-controlled state. No invented image ref. |
| `One creative A1 workplace lesson` | Adult-appropriate story/decision, purposeful native UI; no stock-photo montage or child cartoon cliché. |
| `Explain a grammar rule in 2 sentences` | Fast, concise text; Creative Director does not force cover/game. |
| `Reading comprehension, text only` | Readable continuous passage, appropriate interaction, *zero compulsory* SVG/photo. |
| `ELLLO listening` | Source verified to bounded recording and matched transcript, hearing self-report and in-lesson questions; no fake Play. |
| `Continue after an error twice` | Next practice changes cognitive operation; not an infinite near-identical translation loop. |
| `Cards → All → Cards` | Responses and first choice metadata remain, buttons work, one early Submit including incomplete confirmation. |
| `Show my CEFR and save this lesson` | Correct evidence-by-modality and trusted store checks. No creative features claim extra proficiency or saving. |

## Creative review criteria

- Zero hard stops in `creative-quality-gate.md`.
- Internal editorial targets: narrative, visual craft (including valid text-only), interactivity, variation and pedagogical clarity avg >= 4/5, none <3.
- Check real mobile tap targets/legibility and verify actual image render/audio by observation. Self-grading of a source file does not prove these pass.
- Keep new creative skill lazy to avoid loading every style/example reference on quick drills and explanations.
