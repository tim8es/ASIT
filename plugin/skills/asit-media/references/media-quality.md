# Short audio/video Listen → Answer contract

**Audio is not optional decoration.** An ASIT listening check needs a real bounded audio/video track the learner can hear, content-grounded questions and a user-reported hearing confirmation. Never use 10-minute chapter audio with instructions to stop manually at 30 seconds. Prefer an actual standalone 15–60s recording (shorter if complete), or a verified 61–90s recording for an extended activity. If length is unverified, no scored listening card.

UI preferred: a real external original-site ELLLO link for watching/listening (or legitimate tested MP3 on other permitted lesson paths), native in-chat 2–3 comprehension questions and one final Submit. A minimal embedded player may only be shown when proven to play on that client; neither an SVG Play icon nor an HTML demo grants real audio playback. Generic OGG display was reported silent on one mobile client; prefer real MP3/AAC where legitimate if using external audio files. An actual source and compatibility check beat filename labels.

Do not treat an optional footer link as listening evidence. An audio-targeted lesson includes questions grounded in the verified heard segment plus learner self-report, or it reports listening unavailable.

Track distinct stages: candidate discovery → page/source validation → audio duration and transcript validation → authored original Q&A/rubric → learner opens source → actual learner self-report about hearing and script use → one answer submission → feedback. Clicking a link alone does not prove playback.

Assessment results: `not_assessed` if no audio, missing answer, or unknown hearing; `audio_plus_text_supported` if script read early; `provisional_self_reported_audio_comprehension` if reports hearing and answers are grounded without transcript. No actual host telemetry should be invented. If script disclosed **after** initial attempt, don't retroactively reclassify earlier answer.

The trusted rubric contains source URL, verified selection/duration, exact scoped content evidence held only for lesson review, question IDs, operation gist/detail, accepted variants and required flags. Hide answers/script before first response and never distribute entire ELLLO transcript as part of public card.
