# ASIT Experience Pattern Library — selection menu, not a fixed syllabus

Use an archetype only when it serves the learner's can-do; keep exact activities and rubrics specific to the skill. All experiences require a purposeful interaction with meaningful result.

| Archetype | Best fit | Learner actions | Consequence / feedback | Media requirements |
| --- | --- | --- | --- | --- |
| Visual detective | objects, positions, contrasts | notice -> locate -> explain | native selection updates evidence map; fresh independent description | verified real image or genuinely task-bearing SVG symbolic plan |
| Story mission | everyday language, travel, service | decision -> useful phrase -> new obstacle -> finish | scenario/message state updates with learner decision | optional consistent verified art, never pretend animated game |
| Conversation studio | pragmatic language | inspect replies -> repair tone -> write fresh response | recipient outcome, natural communication feedback | genuine text; multi-turn only if actually multi-turn |
| Grammar lab | form/meaning contrasts | compare minimal pairs -> manipulate diagram/sentence -> apply | observable before/after contrast without revealing unattempted key | optional diagram; not required for abstract rules |
| Reading detective | reading/inference | review continuous document -> identify evidence -> infer -> advise | evidence trail and new recipient reply | textual evidence itself is sufficient |
| Listening studio | real listening | open verified recording -> report hearing -> gist/detail -> respond | honest modality-aware grading | vetted scoped original audio, confirmed duration and user hearing report |
| Word workshop | vocabulary, sentence structure | retrieve -> arrange -> undo -> transfer | visible constructed language + teacher feedback | native controlled selectors/order buttons |
| Timeline case | sequence and cause | inspect events -> reorder -> explain | visible chronology with Undo and semantic review | real source chronology |

**Rotation rule:** Do not select an archetype just because a rich template is easiest to copy. Rotate dominant family when recent verified history indicates repetition; unknown history stays unknown. No more than two sequential pure recognition actions in a default full lesson when context allows.

**Brief template (internal only):** Can-do; purpose/stakes; learner action sequence; meaningful consequence; operation/mode per task; source provenance; responsive presentation; accessible fallback; novel independent transfer. One sentence per field is enough; don't burden output/context with design essays.
