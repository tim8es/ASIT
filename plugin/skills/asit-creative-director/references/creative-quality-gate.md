# Creative Quality Gate — mandatory for full ASIT lessons v0.3.8

Use alongside the authoritative `asit-exercises/references/ui-contract.md`, pedagogical acceptance, answer integrity, media validation and consent Save Gate. Creative scoring is an **editorial self-check**, not an objective metric, automated host proof or data saved to Sheets.

## Hard stops (redesign before rendering / registration)

1. **Empty narrative:** claimed mission is actually unrelated isolated prompts; no credible communicative outcome.
2. **Decorative visual deceit:** main visuals are irrelevant, source is unverified, photo tasks can be answered without seeing the photo, or SVG is passed off as a photo/motion.
3. **Fake controls/media:** any visible interaction fails to change meaningful state, or promises unsupported video, audio, Voice, drag, hotspot, animation or save.
4. **Clone fatigue:** the lesson repeats one operation or recent verified lesson trope despite an available better alternative (excluding explicitly requested focused drills).
5. **Pedagogical regression:** spectacle leaks answers, hides consent, blocks keyboard/mobile, exceeds requested learning budget or obscures the learner's task.

## Editorial scorecard (0–5 each, internal)

- Narrative coherence: goal, stakes, scenario progression and meaningful outcome.
- Visual craft: hierarchy, coherent visual thesis, task relevance and restraint; no visual required for inherently textual goals.
- Interaction depth: actual controlled state and useful feedback, not decorative click-count.
- Variety: cognitive operations, communicative contexts and avoidance of near-duplicates.
- Learning clarity: comprehensible directions, fair assessment, independent transfer and accessibility.

**Target:** average >=4/5 and no dimension <3, **plus zero hard stops**. Scores are a redesign heuristic, never evidence of real user satisfaction or a substitute for host/mobile QA. If the target cannot be met without fake media or accessibility compromises, simplify honestly and disclose limitations rather than add ornament.

## Release path

Can-do and operation selection -> creative concept and media preflight -> freeze rubric/IDs -> source verification -> consented Activity preregistration/readback or UNSAVED -> native rendering with one Submit -> actual host dogfooding. Assess device display and playback only from observed results. Never tell learner a self-score proves UX quality.
