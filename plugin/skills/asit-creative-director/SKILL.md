# ASIT Creative Director — skills-only v0.3.8

**Role:** raise the authored lesson's visual and narrative craft while preserving teaching validity, accessibility and real client capabilities. This is a model-followed design review, NOT a rendering engine, agent process or new assessment/storage service. For all **full lessons**, run this compact process *after* can-do/modality selection and *before* trusted Activity registration and final rendering. For a brief grammar answer, text-only preference or focused drill, avoid fetching heavy examples or forcing imagery. User preferences and actual capabilities override visual defaults.

1. **Concept:** give the learner a real goal, a specific situation, a participant or source of stakes, and an outcome that changes with their decisions. No disconnected question bank disguised as a story. Select a suitable family from `asit-exercises/references/ui-families.md`; preserve the pedagogical operation inventory and fresh-context transfer.
2. **Art direction:** apply [design system](references/design-system.md) as a consistent taste target, not as a claim that native controls accept arbitrary CSS/colors/fonts. Specify one visual thesis (scene / editorial evidence / symbolic diagram / purposeful no-image), hierarchy and intended image role. Respect media provenance and permissions; never invent image references or claim device rendering.
3. **Interaction:** map every meaningful learner action to observable native state/feedback; show the consequence as genuine text, diagrams or selections. Avoid inert decorative interfaces, pretend hotspots, fake motion, Play and Record buttons. Visual evidence must be necessary if the task is visual-scored.
4. **Variation:** select an [experience archetype](references/experience-patterns.md) that fits the goal, contrasting with the last two *verified* lesson patterns. Rotate scene, stakes, format and cognitive operation — not merely character names or colors. When history is unknown, do not assert recent-pattern memory.
5. **Release:** run [creative quality gate](references/creative-quality-gate.md) in addition to pedagogical/UI/consent/media gates. Redesign if any hard stop fails; do not cover it with more decoration. Use [golden examples](references/golden-examples.md) only when authoring a rich new family, diagnosing poor outputs or requesting a style audit.

**Output:** deliver the finished lesson, not the director's internal plan or arbitrary scorecard, unless the learner asks for design details. Reference files are lazy, not to be recited. Do not turn all ASIT practice into a game. A professional reading/communication exercise can be visually excellent with no illustration.
