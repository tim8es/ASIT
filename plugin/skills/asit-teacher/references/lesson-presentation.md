# ASIT full-lesson presentation — source QA reference

Use the native UI contract at ../../asit-exercises/references/ui-contract.md and choose a UI family based on the can-do goal. A meaningful visual scene is suitable for visual-spatial skills; do not add irrelevant diagrams to reading, writing or conversation.

For a multi-task lesson show the goal, honest estimated duration, task count, non-spoiler vocabulary, Cards/All control and completed count. Keep all answers in shared controlled state across view changes, Previous/Next navigation and replay. The default is approximately seven minutes and five scored tasks unless current or verified learner preferences say otherwise.

One logical final Submit must work from every screen, including before all tasks are complete. For incomplete tasks show a confirmation of X answered and Y skipped with real Send X answers / Continue lesson actions. Never invent missing responses or persist a local client state as a verified grade. Final assessment reads trusted rubric and separately registered task IDs; saving requires consent and provider readback.

Do not show solutions before a first attempt. After a finite choice, provide provisional correctness without spoilers; free-text responses are reviewed after Submit. Real media must be verified and failure relabelled honestly. Test keyboard, mobile layout and controls in an actual ChatGPT client. A static skill reference is not a running UI renderer.
