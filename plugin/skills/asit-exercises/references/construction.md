# Construction, sequence, independent response

- `sentence_builder`: present meaningful chunks (e.g., "I called" / "the technician" / "at eight"), provide actual selection/order/reset when available, then ask for independent sentence in a different situation. Guided success isn't independent mastery.
- `card_ordering`: each card is **one word/token**. Native click-to-order + Undo/Reset and keyboard alternative if feasible. Task incomplete until every required word is used. Avoid unsupported drag claims.
- `timeline_ordering`: 3–5 grounded event descriptions, an unambiguous source chronology, real accessible ordering controls, visible chosen sequence, Undo and one new English explanation with `before`, `after` or `because`. Equally possible orderings require teacher review.
- `error_detective`: one meaningful error in context, ask for repair and optional independent variation. Don't pre-display the correction.
- `scenario`: realistic situational decision with a choice and/or supporting English explanation; don't mark partial if explanation is required but empty—keep subtask incomplete.
- `free_production`: learner generates an independent message, explanation, request or account in English; grade communicative success and one/two material errors rather than forcing exact model sentence.
- Preserve original first response, hint exposure, revisions; Submit to trusted rubric after one form submission. Do not claim spoken modality from typing.
