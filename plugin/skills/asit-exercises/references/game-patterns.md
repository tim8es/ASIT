# ASIT game and stateful discovery patterns — v0.3.6

The [UI contract](ui-contract.md) governs all controls and [UI families](ui-families.md) determines whether a game is appropriate. Stateful SVG is a **recommended visual_discovery mechanic**, not compulsory for reading, writing, listening or explicitly text-only goals.

**Visual scene pattern:** native radio prediction (no correctness before learner acts) → native `button` setting stage state → visibly updated SVG coordinates or assignment → provisional finite feedback → optional fresh-context transfer. The SVG is symbolic `visual_symbols`, not a photograph, verified animation or touch-hotspot. Use the corrected [complete-native-lesson](complete-native-lesson.md) as the reference implementation.

**Image detective:** verify suitable real photo in current turn, display it immediately above input without solution-bearing text; textual aliases reviewed after Submit. If unavailable, revise the entire task, rubric and modality before preregistration.

**Delivery assignments:** native `select` pairs 2–3 meaningful items, updated visible statuses, Undo/Reset and independent decision consequence. Never claim drag-and-drop or external executor.

No game victory implies CEFR mastery, provider write or secure first try. On actual host test `predict → interact → observe → replay → reattempt → Cards/All → Submit` plus accessible keyboard/mobile interaction. Native UI references are copy-adapt instructions only, not running scripts included in the plugin.
