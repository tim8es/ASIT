# Media, dialogue and accessibility

- **Open conversation/role-play**: often plain multi-turn ChatGPT. A `dialogue` grade needs two or more real responsive learner turns; one textarea is preparation only. Keep flow natural; don't turn every utterance into an instant correction.
- **Voice**: in same chat, user starts native Voice manually. ChatGPT form cannot force Voice on. Assess pronunciation/prosody only from actual accessible audio, not transcripts. Use `asit-voice`.
- **External listening/video**: user opens a verified short original-site link, genuinely hears/watch, returns to answer in native radio/input/textarea. The teacher checks hearing and transcript use after the response, not UI click counts. ELLLO media selection handled by `asit-media`.
- **Trusted media sources**: no invented MP3 URL, code-only Play button, fake waveform, hidden script disclosure or unsupported video embed. Mobile page loading is not proof sound plays.
- **Popover inline aid**: choose working contextual underlined hint only if it remains inline; otherwise keep sentence continuous and place explanation link below it. No fake parallel chat feature.
- **Accessible fallback**: if actual picture, audio, region control, Voice or native UI isn't available, switch to a truthful text/select alternative and change evidence modality/status. Do not assign full scores for a modality the learner could not perform.
