# ASIT lessons — source-first planner (v0.3.4)

`asit-core` chooses sequencing and learner goals; `asit-english` supplies language criteria; `asit-exercises` owns functional controls; `asit-media` verifies real ELLLO assets; `asit-assessment` evaluates submissions; `asit-progress` saves with consent. No executor or auto-running application exists.

## ALWAYS-on complete lesson delivery contract

**Default for "Продолжим" and every full lesson:** load [rich-default lesson contract](references/rich-default-lesson.md) and [complete native interactive lesson reference](../asit-exercises/references/complete-native-lesson.md) even if the user asked for **no** particular format. **NEVER** return a purely prose lesson, five unresponsive text questions or a pictureless display *just because no photo was found*. Use an actual SVG visual-symbol scene plus controlled state and feedback instead, with correctly relabelled rubric/modality. At least one scene event, one prediction and an actual learner-triggered manipulation must be observable. Keep authentic photo labels only for real tool-verified images. The standalone `parcel-mission.html` cannot run inside this Skills-only plugin; **native controls must be authored in each lesson**. Evaluate all native widgets before Activity preregistration. If genuine rendering is unsupported, state exact limitation and offer honest functional fallback; never pretend an interactive widget worked.

## Mandatory proof-of-media preflight (blocks Save Gate)

Read [media provenance and renderability](references/media-provenance.md) **before** registering a photo/image-scored Activity. A string that resembles `turn...image...` is NOT proof of a returned tool result; never invent `AsyncImage.ref` or refer to unseen prior-turn image IDs. If no actually returned and inspected asset exists, substitute text/diagram and revise **the task type, modality, rubric and Activity before preregistration**, or make that item not assessed when the failure is discovered after rendering. A static image cannot be counted as CSS animation. Do not assert that a client displayed media merely because a source lookup succeeded.

Use [stateful game patterns](../asit-exercises/references/game-patterns.md) when an interactive mini-game or motion is requested. Genuine host-supported state transitions, after-input feedback and accessible fallback are required; game templates do not themselves execute plugin code. On repeated intentional skips, apply [two-axis format adaptation](../asit-core/references/format-adaptation.md), not a presumed ability deficit.

**Evidence-driven planning:** before selecting tasks consult [selection invariants](../asit-core/references/selection-invariants.md) and [English can-do starter criteria](../asit-english/references/can-do-starters.md), then choose just one original communication outcome.

## Non-negotiable pre-render order

1. **Choose can-do + lesson style:** read [lesson quality gate](references/lesson-quality-gate.md), [answer integrity](references/answer-integrity.md) and [visual lesson standard](references/visual-lesson-standard.md). Current learner duration/count/format take precedence over Config. Decide complete storyline and 4–6 distinct sections for a requested 40-minute lesson; never fill time with repeated question templates.
2. **Check media and actual response affordances before selecting tasks.** For suitable 15+ minute or explicitly audio-targeted English sessions, run `asit-media` source discovery and verification before writing the blueprint. For visual topics, make two distinct assessed questions depend on actual images, not icon/emoji/text stand-ins. Original recordings stay on their host; an external original-page link beside Q&A is valid only with verified source, duration and learner hearing confirmation. Voice requires a real Voice session. Missing media = visibly and accurately relabeled fallback.
3. **Freeze ONE trusted lesson blueprint:** stable session/lesson/parent Attempt ID; one immutable Activity per scored task with rubric, actual modality/operation, source evidence, response type, allowed variants, required flag, hint policy and privacy. Distinguish image choice, visual symbol recognition, reading, listening, guided construction and independent production. Apply entire-lesson answer-leak audit. For semantic original writing, do not exact-string grade and do not show copyable models.
4. **Check inventory strictly:** 4–7-minute 5-task lessons need >=3 operations, >=3 working input patterns, <=2 simple multiple choice and a fresh-context original response available as an **optional, short task** after repeated deliberate skips (never force the same textarea to the first half). 20+ minute lessons require >=5 operations and <=35% single-choice recognition, plus verified suitable listening when available. Never have three consecutive tasks with the same operation; reject merely reskinned radios. One genuine responsive predict → change → feedback cycle where visual content supports it.
5. **Save Gate preflight:** Register separate Activities for every assessed subtask: if consent active, verify unique learner-owned workbook, owner, nine v2 headers, live Config consent/revision, stable uniqueness; preregister every graded Activity, read back exact rubric and metadata BEFORE UI display. Do not create historical Activities after display. If not possible, show a clearly **UNSAVED** full lesson instead of claiming save-ready. A stored preceding attempt is not proof of next lesson readiness.
6. **Render:** a concise useful RU introduction (goal, context, grammar, short vocabulary), 16:9 cover for suitable visual topics, image evidence immediately adjacent to its answer input, one task per card with native working controls, Cards/All selector with retained answers, Undo/Reset for order, immediate provisional correctness for deterministic items, semantic review for original writing, one canonical final Submit and working early-finish confirmation. Never fake image hotspots, drag-and-drop, motion, audio playback, microphone, timers or media duration.
7. **After answer:** hand to `asit-assessment` for validate → grade → save/readback → progress projections. By default render only one complete next full lesson in the same response unless paused. Continue different communicative skills after two remediation cycles; never infer a CEFR level from guided selection or text-only work.

## Specific anti-repetition rule

Read the last two lesson task mixes when verified. Rotate **cognitive operations**, not themes alone. If original-writing tasks were deliberately skipped twice, prioritize a **different input mechanic and visual game**, and keep one voluntary 3–8-word self-generated reply for a new recipient/context within the lesson (usually the transfer task); no forced long textarea, no inferred poor proficiency. Skips are `not_assessed`, not mistakes. Do not copy an earlier completed scaffold into an alleged independent transfer item.

**Native interactive verdict:** show provisional Correct / Incorrect — Try again **only after learner input**; never show a spoiler before an attempt. Keep exactly **one final Submit**, including early-completion confirmation, and do not treat provisional UI feedback as a stored graded Attempt.

## Required final check

Run the [lesson quality gate](references/lesson-quality-gate.md) **before** storing any new rubric and again before display. If pictures/audio cannot be verified, correct type and rubric before pre-registration. Never claim a full listening lesson based only on reading a transcript or a footer link. Keep a single Submit with separate per-task evidence and privacy rules.
