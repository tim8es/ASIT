# ASIT visual learning standard — v0.3.6

For mandatory UX behavior refer to [UI contract](../../asit-exercises/references/ui-contract.md). Visuals must be **task-relevant**, not a mandatory decorative quota. This reference governs visual evidence only; it cannot override a user-selected text-only or accessibility mode.

- Spatial, object, map, visual comparison and process-learning tasks should use a visible verified image or a **drawn SVG diagram that contains necessary answer evidence**. When the task requires authentic picture recognition, use only tool-confirmed current-turn visual and a non-spoiling alt; no invented refs.
- If a real visual asset is unavailable, replace photo recognition with an actual diagram operation (`visual_symbols`) where appropriate, and change rubric/modality before writing Activity. If neither picture nor diagram is renderable, use a correctly labeled reading/description alternative or mark unusable visual evidence `not_assessed`.
- Only an actual after-action state change can be called interactive scene change; instant SVG coordinate switch isn't smooth animation. A static AsyncImage cannot be a hotspot. Provide native selection and keyboard alternative.
- Reading comprehension, textual error repair and professional writing may use **zero** photo-scored tasks and no SVG. Richness can come from actual text evidence, meaningful choices and interactive revisions.
- Images with answer words in captions, exposed alt, glossary, or prompt before learner response are invalid for answer-independent image labeling. Show image adjacent to its input and defer ambiguous synonyms to semantic grading.
- Useful inspiration: notice → predict → manipulate/compare → explain → apply, **when genuine discovery enhances the objective**; not compulsory for every English can-do.
