# ASIT scenario bank — v0.3.7 (optional only when planning a full lesson)

Select a scenario **after** observable can-do and the appropriate [UI family](../../asit-exercises/references/ui-families.md). This is *not* an obligatory visual-game catalog. The communication objective, not availability of a courier SVG, drives learning mechanics. Do not repeat the dominant scenario/operation in the previous two verified lessons when a different valid one fits.

| Goal / family | Grounded scenario | Actions | Distinct transfer |
| --- | --- | --- | --- |
| Objects and place / visual_discovery | Apartment lost-and-found: actual photo or a meaningful symbolic room layout | predict position, move/change a scene, retrieve another object, construct a request | ask a different recipient about a new object |
| Directions / visual_discovery | Fictional bus detour map with a blocked path | infer, switch route with native selector, observe path consequence, repair instructions | explain an alternate route with changed constraint |
| Polite English / communication_mission | Café substitution or customer support request | evaluate a message, choose appropriate tone, repair one detail, compose new request | contact a different recipient with distinct need |
| Workplace writing / communication_mission | Team discussion and follow-up note | compare messages, identify missing commitment, order information, write concise reply | send new request about another task |
| Reading/inference / reading_reasoning | Realistic notice, article excerpt or two conflicting messages | gist, relevant evidence, sequence, inference, short response | use facts to advise a new recipient |
| Grammar focus / focused_drill | Error detective across multiple independent situations | spot error, repair, compare meaning, recall unassisted | solve a new related micro-case |
| Hearing in context / listening_lab | Verified specific ELLLO recording (NOT fictional course audio) | listen, report hearing mode, answer gist/detail, summarize or request clarification | new question based only on confirmed heard facts |
| Interaction / dialogue_voice | Travel or professional interview with multiple actual turns | listen/read a real reply, respond, clarify, negotiate outcome | brief end-of-dialogue summary |

For every new task privately specify task ID, operation, modality, key/rubric, native control, actual evidence, optionality, answer-integrity constraints and effect on a real scenario. No five cloned questions with different icons, no fake clickable photo regions, no invented audio player or CEFR evidence. If there is no suitable true visual source for a visual target, use a truthful SVG diagram with symbol modality. If the goal is reading/writing, use text with meaningful native interactivity and **do not inject irrelevant SVG**.
