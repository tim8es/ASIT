# ASIT rich-default lesson — v0.3.6

This file is a **brief pedagogy-specific contract**. For all interface behavior and acceptance, use the authoritative [UI contract](../../asit-exercises/references/ui-contract.md); for component selection use [UI families](../../asit-exercises/references/ui-families.md). Older rigid five-step Parcel Mission layouts are examples, **not** a mandate for a moving SVG in every lesson.

## Default after "Продолжим"

Choose learner's established can-do, due review and actual recent evidence. Use **approximately 7 minutes, 5 graded tasks** only if there is no explicit duration/count preference. If goal calls for reading/writing instead of visual manipulation, deliver rich **task-relevant** reading/writing interface, not an irrelevant picture or motion. For visual-spatial goals use a verified real asset or genuinely task-dependent labeled SVG diagram. For 15+ minute general English lessons assess availability of appropriate short verified ELLLO listening; never make up sound or grade unheard audio.

Plan one goal and one coherent situation. For five tasks use at least three distinct cognitive operations and at most two simple recognition choices. Scaffold perception/interpretation to a meaningful fresh-context transfer; after deliberate writing skips make that text response short and optional, leaving writing `not_assessed` if skipped. Rotate families and dominant operation from verified recent lessons. Limit focused remediation to two cycles, then return to broader learning.

## Authoring sequence

1. Determine objective, level evidence, user time/count/format, UI capabilities and actual available media.
2. Choose family + task inventory (`task_id | rubric | operation | modality | control | evidence | feedback`); check independent-answer leakage and specific media provenance.
3. **Before any consented write**, validate per-task trusted Activities, exact IDs/accepted variants and UI feasibility. Perform pre-registration/readback when permitted; otherwise show an explicitly unsaved lesson.
4. Render one complete native lesson with the shared shell, working controls, legitimate local feedback and one actual Submit. For inability to display essential media after rendering mark affected task `not_assessed`.
5. On Submit use `asit-assessment` for trusted grading and consented Save Gate, then auto-continue when learner has not paused. Never claim success from local client state.

Do not force illustration into advanced text analysis, force a static form into actual Voice/dialogue, or use a text-only fallback just because verified photographs were unavailable for a naturally spatial lesson. Native symbolic SVG is appropriate for a spatial scene when genuinely useful.
