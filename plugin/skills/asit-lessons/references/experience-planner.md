# Experience planner: story, varied retrieval, bounded remediation

Load only for full structured lessons and recurring learner errors; do not load for quick corrections. This is a policy for the language model, not an automatically running scheduler.

## Build a lesson from evidence
Input: learner can-do goal, observed error family, last two learner operations, support level, time budget, and currently working media/UI tools. Never pretend a cross-chat history exists without verified storage.

1. Begin with one communicative real-world mission, for example locating missing keys, explaining where possessions are in a flat, or arranging a visit. The four tasks contribute to this outcome.
2. Four-step arc: notice/interpret -> compare/reason -> manipulate/repair -> independently communicate in a fresh situation. Prefer at least three distinct cognitive operations (e.g. image_choice, error_detective, sentence_builder, scenario). A new picture or control skin does not make an operation different.
3. Make visuals useful: an image must provide task evidence, not merely decorate a translation. Place image directly above the input when doing image_label and avoid alt/captions revealing the answer. Use honest accessible fallback.
4. When actual listening is an objective, follow asit-media: verified ELLLO track, exact conversation, questions, and hearing/transcript-use report in the lesson. A footer link is not listening practice.
5. End with independent communication and a clear closing point; one final Submit for a static lesson; vocabulary last.

## Anti-loop and adaptive selection
- Define same error by a genuine repeated independent mistake, e.g. missing be, confusing their/them, singular/plural agreement, or a place preposition. Local answer selection retries are NOT independent attempts.
- After first error, explain a single high-impact reason and give a fresh example.
- After the same error appears twice, SWITCH operation rather than issuing another near-identical translation. For missing is/are: translation -> error_detective -> sentence_builder or pictured explanation; for prepositions: contrast two scenes; for articles: introduce then refer back to an object.
- After two remediation cycles, close the loop: briefly summarize correct patterns, remaining gap, honest evidence status and optional next review. No endless quiz chain, unless learner explicitly asks for continued drilling.
- A correct scaffolded answer does not prove independent mastery; ask for one fresh unaided use only if needed, then close.
- Never claim exact CEFR proficiency from a single task or unanswered modality.

## Example mission: The Missing Keys
Visitor needs to retrieve belongings from an apartment. 1: select a location from a meaningful scene, 2: explain in/on/at, 3: repair a note missing is/are, 4: send a short helpful message using a then the. If validated audio is available, replace one task with authentic ELLLO listening, without pretending ELLLO characters voiced the apartment story.

## Release quality gate
Reject a full lesson with three near-identical translation prompts, solely decorative visuals where image evidence was promised, a listening task represented only by a link, unbounded follow-up drills, a disabled Submit, or unverified saving.
Honor learner-requested text-only format, accessibility constraints, and explicit requests for a fixed drill.
