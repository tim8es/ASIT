# First-run example interactions (synthetic)

These are illustrative branches for an agent, not a fixed script, personal profile or mandatory form.

### New learner says "I want to learn English"

The agent looks for an existing private state; if absent, briefly explains that optional Google Sheets storage lets it retain progress across chats and asks permission before creating it. Then it asks one relevant goal question, such as what the learner most wants to do in English. It does **not** insist on knowing their name, first language or job.

### A learner wants travel communication

The agent builds a small communicative graph involving clarification, common requests and getting around, and starts at difficulty suggested by their answers. It does not preload workplace/project-management vocabulary or a B2 target.

### Returning user says "Only five minutes today"

The agent reads the current goals and due items, uses a compact exercise, assesses and records the actual attempt with a short review rather than overwriting a 20-minute session preference forever. It should not repeat the onboarding.

### Learner wants no answer logs

Keep teaching inside ChatGPT. Do not send raw answers to third-party systems. If they consent to \`summary_only\`, store a non-verbatim evidence summary; if they choose \`off\`, store nothing. Disclose when the next chat cannot reliably restore transient work.

### Learner asks about pronunciation

Use actual accessible audio only when the client supports it; otherwise explain the limitation and offer spelling or contrastive sound explanations without claiming an audio assessment.

### Learner changes goals

Archive old plan revisions, keep valid observed skills, construct new priorities, and show why those new skills matter; preserve user agency.
