# Quality evaluation checkpoints

CI now verifies a complete **synthetic learner state transition**: empty setup, competency selection, partial initial production, review scheduling, guided attempt, independent retry in another session, qualified cross-context transfer, changed priority and privacy-safe storage serialization.

This demonstrates deterministic policy invariants, not live ChatGPT rendering, connector authorization or actual learning gains.

Live acceptance is documented in [manual acceptance](manual-acceptance.md), and full public release remains blocked by [residual Git object accessibility](publication.md). Never use a real learner's reply as a public fixture.
