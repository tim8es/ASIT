# Pedagogical evaluations (manual + scenario based)

Beyond unit tests, evaluate the full teacher with *synthetic* personas, including:
- beginner learner who cannot construct full sentences;
- B1 learner with workplace goals but unfamiliar industry;
- advanced learner who wants spontaneous discussion;
- learner who refuses cloud logging;
- returning learner whose earlier assessment was incorrect;
- learner who changes goals from work to travel;
- learner who has no audio capability or uses a UI without native widgets.

For each scenario check: goal alignment; appropriate language level; targeted retrieval; spontaneous learner production; selection of high-value errors; retry; no false mastery; consent; durable evidence when authorized; plan change rationale; uncertainty honesty. Store fictional task answers only; no actual user records.

Human review compares linguistic naturalness and communicative usefulness. A green unit-test run is **not** evidence the instructional strategy improves English acquisition.
