# Карта источников

Проверено по публичным материалам ASIT на 2026-10-27. Репозиторий подтверждает устройство исходников, а не поведение установленного плагина на каждом устройстве.

## Источники

| Источник | Что поддерживает | Ограничение |
|---|---|---|
| Issue #43 | Идея, опыт автора и требования к истории | Постановка задачи и отчёт автора |
| README и docs/ARCHITECTURE.md | Назначение ASIT и границы исходного проекта | Не подтверждают реальный UI |
| PR #14 и #15 | Отчёты о неестественной озвучке и мобильном плеере без звука | Отдельные пользовательские наблюдения |
| PR #16 | Случай с аудиозаписью длительностью 10:40 | Описанный автором эпизод |
| PR #23 и #36 | Изменение архитектуры и описанный сбой отображения | PR #36 открыт и не доказывает текущее поведение |
| GitHub ASIT | Открытые исходники | Код сам по себе не устанавливает плагин |

## Сцены

| Сцены | Содержание |
|---|---|
| 01–03 | Замысел и разница между ответом и обучением |
| 04–08 | Вход в урок, практика и обратная связь; для продуктовых экранов нужны настоящие снимки |
| 09–11 | Три отдельных описанных наблюдения: длинное аудио, тишина на телефоне, один сбой загрузки |

Таймкоды и полный текст озвучки находятся в `speaker-notes.md`. Демо-аудио в папке `outputs` синтетическое и используется только для оценки темпа.
