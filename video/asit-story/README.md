# ASIT Story Deck

Короткий зрительский рассказ на русском: 14 сцен, около 2:42 с демо-озвучкой. Это автономная HTML-презентация для живого рассказа; она не устанавливает плагин и не является видеофайлом.

## Открыть и листать

Откройте `index.html` в Chrome, Edge или Firefox. Сборка и сервер не нужны.

- Вперёд / назад: стрелки, Page Down / Page Up, Space.
- К первой / последней сцене: Home / End.
- Полный экран: F или кнопка в шапке.
- Прогресс: ползунок внизу.
- Сценарий, роли и переходы: `speaker-notes.md`.

В этой версии убраны сведения о внутреннем устройстве, которые зрителю не помогают понять историю.

## Реальные снимки ASIT

В каталоге `assets/captures/` пока нет снимков продукта. Слоты перечислены в `missing-assets.md`. Как только реальные PNG появятся с указанными именами, презентация покажет их автоматически. Макеты интерфейса вместо скриншотов не используются.

## Источники

`source-manifest.md` связывает историю и наблюдения с публичными источниками. Реальные случаи описаны как отдельные наблюдения, а не как статистика для каждого запуска.
