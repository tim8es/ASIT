# Скриншоты, необходимые для зрительской версии

Реальные экраны ASIT не были доступны в подключённом браузере, поэтому в текущей версии видны места для снимков. Не заменяйте их макетами ChatGPT.

Положите безопасные PNG в `assets/captures/` с этими именами — HTML подхватит файлы автоматически:

| Файл | Кадр |
|---|---|
| `01-chatgpt-asit.png` | ASIT внутри разговора ChatGPT |
| `02-home-menu.png` | Меню выбора урока |
| `03-lesson-cover.png` | Обложка выбранного урока |
| `04-cards.png` | Урок в режиме карточек |
| `05-all.png` | Тот же урок целиком |
| `07-feedback-result.png` | Ответ и обратная связь после упражнения |

Перед съёмкой откройте синтетический тестовый чат. Уберите имена, чужие диалоги, личные ответы и реальные таблицы прогресса. Снимки должны быть настоящими экранами установленного ASIT; сохраните один и тот же урок для кадров 03–07.
