# Cloze / retrieval
**Use:** recall a missing target structure or word in a meaningful sentence; one or two gaps, not a trivia worksheet.
**Input:** native short text field; optional multiple short items in the single lesson form.
**Hints:** semantic cue → beginning of word/structure → model only after assessment.
**Feedback:** show accepted alternatives, correct one form error, ask independent use in new context on a later turn.
**Evidence:** typed form retrieval only; not speech. Accept grammatical variants preserving intention; avoid exposing answer in vocabulary recap.
**Fallback:** ordinary labelled blank and a numbered typed answer.
