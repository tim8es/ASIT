# Grounded image choice
**Use:** identify or describe a real relevant scene/object with target vocabulary or interpretation.
**Input:** an actually resolved, suitable image and 2–4 labelled answer choices or short typed description. Supply alt text for accessibility without leaking answer.
**Hints:** refer to visual features or intended meaning without giving the correct option.
**Feedback:** name observed evidence; if image failed to render, do not grade picture identification.
**Evidence:** grounded image-based recognition or meaning, not speaking.
**Fallback:** an equivalent text description task, explicitly marked different evidence; never fabricate the original image.
