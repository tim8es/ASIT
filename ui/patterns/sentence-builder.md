# Sentence builder
**Use:** construct a sentence with the target word order or grammar, in communicative context.
**Input:** draggable tokens only with usable controls; default typed sentence or sequence selector.
**Hints:** highlight tense or subject → offer partial frame → show complete model only after an attempt.
**Feedback:** contrast order with intended meaning; next independent message in a different situation.
**Evidence:** construction in typed text, not oral fluency.
**Fallback:** one textarea, or choose order by token numbers.
