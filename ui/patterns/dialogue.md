# Natural dialogue
**Use:** interaction, negotiation, clarification and sustained conversation.
**Input:** ordinary chat when back-and-forth is itself required; in a single seven-minute form use 1–2 contextual turns with separate fields, not a fake live conversation.
**Hints:** pragmatic intent cue → short sentence frame.
**Feedback:** judge appropriateness, clarity, and repair strategy, not only grammar.
**Evidence:** typed interaction unless genuine spoken audio was observed separately.
**Fallback:** normal text conversation. Don't force widgets that interrupt flow.
