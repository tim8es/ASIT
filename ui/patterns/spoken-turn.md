# Real spoken turn
**Use:** short actual speech in meaningful context, when supported and separately authorized.
**Input:** native voice or audio capture supported by client. Never fake a recording button or infer actual speech from a typed transcript.
**Hints:** short prompt, then gentle cue; avoid showing entire spoken answer.
**Feedback:** assess only audible aspects genuinely available; pronunciation/fluency unassessed if no original audio is heard.
**Evidence:** spoken audio production or interaction only with actual observable media.
**Fallback:** offer an explicitly labelled typed practice task; mark the spoken skill unassessed.
