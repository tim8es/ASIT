# Meaning choice
**Use:** distinguish an important meaning or implication, using 2–4 clear plausible options.
**Input:** native radio/select for one choice; request a short reason only when it improves evidence.
**Hints:** point to context, not which option is right.
**Feedback:** explain why selected option fits/does not fit, including valid ambiguity.
**Evidence:** recognition or comprehension; never spontaneous production or speaking.
**Fallback:** learner types the option number and any rationale.
